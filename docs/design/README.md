# Decisões de Design & Design System

Este diretório armazena a documentação, auditorias visuais, especificações de componentes e tokens do Design System do Aprumo.

- `MASTER.md`: Guia mestre de tokens, tipografia, cores e regras de espaçamento.
- `ACCESSIBILITY.md`: Checklist e evidências de conformidade WCAG 2.2 AA.
- `COMPONENTS.md`: Catálogo e diretrizes de uso dos componentes de `packages/ui`.
