# Evidências Clínicas & Fundamentação Científica

Este diretório armazena a síntese de literatura e justificativas baseadas em evidências para os procedimentos clínicos do Aprumo:

- Análise do Comportamento Aplicada (ABA) e protocolos DTT, NET, Encadeamento e Fluência;
- Modelo Denver de Intervenção Precoce (ESDM);
- Avaliação de Preferências (MSWO, Escolha Pareada, Operante Livre);
- Suportes Visuais, Agendas e Quadros de Fichas;
- Limites de tempo de tela e ergonomia para neurodesenvolvimento (SBP, 2024; AAP).
